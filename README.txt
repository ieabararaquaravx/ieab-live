IEAB Live - GitHub Pages

Arquivos prontos para publicar gratuitamente no GitHub Pages.

Canal configurado:
https://www.youtube.com/@IEABLive

Link permanente da live:
https://www.youtube.com/@IEABLive/live

Como publicar:
1. Crie um repositorio no GitHub, por exemplo: ieabculto.github.io
2. Envie todos estes arquivos para a raiz do repositorio.
3. No GitHub, entre em Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Escolha branch main e pasta /root.
6. Salve.
7. Acesse o endereco gerado pelo GitHub Pages.
